= ONTAP tools를 사용하여 데이터 저장소 보호를 위한 클러스터 구성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP tools for VMware vSphere를 사용하여 클러스터 구성(호스트-스토리지 근접성) 설정을 구성하면 가상화 환경에서 효율적인 데이터스토어 보호 및 간소화된 장애 조치 관리가 가능합니다.

.시작하기 전에
* vSphere에 대한 관리자 권한이 있는지 확인합니다.
* 클러스터 구성 설정은 균일 구성과 비균일 구성 모두에 적용 가능하며, 액세스 설정은 AFD 유형의 관계에만 적용됩니다.


.단계
. vSphere 클라이언트에서 호스트 클러스터를 마우스 오른쪽 버튼으로 클릭하고 *클러스터 보호 구성*을 선택합니다.
+

NOTE: 클러스터에 이미 클러스터 구성이 있는 경우 이 옵션을 사용하면 기존 구성을 편집할 수 있습니다.

. *구성 유형* 창에서:
+
.. 두 장애 도메인의 호스트가 양쪽 사이트의 스토리지 리소스에 액세스할 수 있도록 하려면 *균일*을 선택하십시오. 장애 도메인은 하드웨어 및 인프라 구성 요소 그룹입니다. 각 호스트를 양쪽 사이트의 장애 도메인에 할당하십시오.
.. 각 사이트의 호스트가 해당 사이트의 스토리지에만 액세스하도록 제한하려면 *비균일*을 선택하십시오. 호스트를 장애 도메인에 적절히 할당하십시오.
.. 장애 도메인 이름을 입력하십시오. 기본값은 "Site A"와 "Site B"입니다. 이 값은 편집할 수 있습니다. 사이트 이름은 소스 및 대상 장애 도메인에 매핑됩니다. 사용자 인터페이스는 입력하는 동안 입력 내용을 검증하고 지원되지 않는 문자나 문자 제한을 초과하는 값이 있는 경우 메시지를 표시합니다.
+

NOTE: 구성 유형은 설정 후에는 수정할 수 없습니다. 구성 유형을 변경하려면 클러스터 구성을 삭제하고 원하는 설정으로 새 구성을 생성하십시오.



. 다음 * 을 선택합니다.
. *호스트* 창에서 각 호스트를 소스 장애 도메인 또는 대상 장애 도메인 중 하나에 할당합니다. 모든 호스트를 할당해야 하며, 한 호스트가 두 사이트 모두에 속할 수 없습니다. 마법사에 표시되는 사이트 이름은 소스 및 대상 장애 도메인 이름입니다. 모든 호스트 할당이 완료되면 *다음* 버튼이 활성화됩니다.
. 다음 * 을 선택합니다.
. *스토리지 SVM 피어* 페이지에서 각 SVM을 적절한 사이트에 할당하십시오. 여러 개의 SVM 피어를 할당할 수 있지만, 각 사이트에는 최소 하나씩 할당되어야 합니다. SVM을 한 사이트에 할당하면 해당 SVM의 피어인 SVM은 자동으로 반대쪽 사이트에 할당됩니다.
. 다음 * 을 선택합니다.
. *요약* 페이지를 검토하십시오. 각 장애 도메인에 대한 클러스터 구성 설정을 확인하십시오.
. 구성을 적용하려면 *생성*을 선택합니다.
. 기존 클러스터 보호 구성을 보거나 편집하려면:
+
.. ONTAP tools 플러그인 보기로 이동합니다.
.. *보호* > *클러스터 보호 구성*으로 이동합니다.
.. 클러스터를 선택하여 현재 구성을 확인합니다.
.. 세로 점 세 개(…)를 클릭하고 *편집*을 선택하여 구성을 수정합니다. 마법사에 현재 설정이 표시되며 편집할 수 있습니다.
+
image:../media/edit-protection.png["클러스터 보호 구성 편집"]





.결과
구성이 적용되었으며, ONTAP tools 플러그인에서 확인하거나 편집할 수 있습니다.
