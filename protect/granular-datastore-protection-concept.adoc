= ONTAP 툴의 세분화된 데이터스토어 보호 자격 기준
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
전체 클러스터를 보호하는 대신, 호스트 클러스터 내에서 선택한 VMFS 데이터스토어를 보호하기 위해 세분화된 데이터스토어 보호 기능을 사용하십시오.

세부적인 데이터스토어 보호 기능은 ONTAP tools for VMware vSphere 10.6 이상 버전에서 사용할 수 있습니다. 이 기능은 클러스터 전체를 대상으로 하는 선택 방식 대신 데이터스토어 수준의 보호 계획을 수립할 수 있도록 지원합니다.

이 기능을 사용하면 다음을 수행할 수 있습니다.

* 호스트 클러스터에서 선택한 데이터 저장소만 보호합니다.
* 선택한 데이터 저장소를 보호 그룹으로 묶습니다.
* SnapMirror 관계 및 정책을 보호 그룹 수준에서 적용합니다.
* 동일한 호스트 클러스터 내에서 서로 다른 데이터 저장소 그룹에 대해 서로 다른 보호 방식을 사용하십시오.
* 단일 호스트 클러스터에 여러 보호 설정을 할당합니다.
* 동일한 스토리지 가상 머신(SVM), 서로 다른 SVM 또는 서로 다른 스토리지 시스템에 걸쳐 보호 설정을 구성할 수 있습니다.
* 호스트 클러스터의 일부 데이터 저장소는 보호되지 않은 상태로 유지하십시오.
* 개별 데이터 저장소에 대한 보호 기능을 제거합니다.
* 프로비저닝 중에 데이터 저장소를 보호합니다.


이 기능은 iSCSI 또는 FC 프로토콜을 사용하는 VMFS 데이터스토어만 지원합니다.

다음 정책 유형을 적격 데이터 저장소에 사용할 수 있습니다.

* *AutomatedFailOverDuplex (AFD)*
+
** *균일한 호스트 구성*: 양쪽 사이트의 호스트 모두 보호된 데이터 저장소에 액세스할 수 있습니다.
** *Non-uniform host configuration*: 호스트 액세스는 사이트별 호스트로 제한됩니다.


* *비동기*: 대상 사이트는 복구를 위해 비동기 복사본을 유지합니다.


팬아웃 보호는 기본 사이트 간의 AFD와 세 번째 사이트로의 비동기 복제를 결합할 수 있습니다.

== 자격 평가

자격 심사는 목록 작성과 선정의 두 단계로 진행됩니다.

데이터 저장소는 다음 기준을 모두 충족하는 경우에만 세부적인 데이터 저장소 보호 목록에 포함됩니다.

* 데이터 저장소 유형은 VMFS입니다.
* 프로토콜은 iSCSI 또는 FC입니다.
* 데이터 저장소는 선택된 호스트 클러스터의 호스트에만 마운트됩니다.
* ONTAP 도구는 데이터 저장소가 vCenter Server에서 선택한 호스트 클러스터에 있는 경우 해당 데이터 저장소의 보호 여부를 평가할 수 있습니다.


데이터 저장소가 목록에 추가된 후에는 다음 요구 사항을 모두 충족하는 경우에만 보호 대상으로 선택할 수 있습니다.

* 데이터 저장소는 아직 보호되지 않았습니다.
* 데이터 저장소는 선택된 호스트 클러스터 내에서만 마운트된 상태로 유지됩니다.
* 소스 및 타겟 SVM은 ONTAP tools에서 피어링 및 온보딩됩니다.
* ONTAP 버전은 9.15.1 이상입니다.
* 2x2 및 4x4 소스 및 타겟 클러스터 노드 조합만 지원됩니다.
* MetroCluster 구성은 해당되지 않습니다.
* 데이터스토어를 지원하는 FlexVol 볼륨 또는 LUN이 기존 일관성 그룹의 일부가 아닙니다.
* 데이터스토어를 지원하는 FlexVol 볼륨 또는 LUN은 기존 SnapMirror 관계에 포함되어 있지 않습니다.


다음과 같은 작동 제한 및 동작을 고려하십시오.

* 데이터 저장소 보호를 구성하기 전에 클러스터 근접성을 구성하십시오.
* 단일 호스트 클러스터는 균일 AFD 구성 또는 비균일 AFD 구성 중 하나만 사용할 수 있으며, 둘 다 사용할 수는 없습니다.
* 보호 그룹 간 데이터 저장소 이동은 지원되지 않습니다. 대상 그룹에서 보호를 해제한 다음 다시 보호하십시오.
* 동일한 호스트 클러스터 내에서 하나의 소스와 여러 개의 서로 다른 타겟을 사용하는 교차 SVM 보호는 지원되지 않습니다.
* 사용자 지정 비동기 정책은 지원되지 않습니다. 기본 ONTAP 비동기 정책을 사용하십시오.
* 3차 구성 또는 비동기 전용 구성에서는 비동기 관계 정리가 수동으로 수행됩니다.
* ONTAP System Manager에서 페일오버를 트리거합니다. ONTAP tools 외부에서 ONTAP Mediator를 구성합니다.


ONTAP tools for VMware vSphere 10.5에서 업그레이드할 경우 기존 호스트 클러스터 보호 설정이 세분화된 데이터스토어 보호로 자동 변환됩니다. 업그레이드 후 보호 그룹 및 데이터스토어 멤버십을 확인하십시오.
