= ONTAP tools for VMware vSphere 10.6의 새로운 기능

[role="lead"]
ONTAP tools for VMware vSphere 10.6의 새로운 기능과 향상된 사항에 대해 알아보세요.



[[granular-datastore-protection]]
== 세부적인 데이터 저장소 보호

ONTAP tools 10.6에서는 데이터스토어 수준 보호 기능이 도입되어 전체 호스트 클러스터 대신 선택한 데이터스토어에 보호를 적용할 수 있습니다.

주요 개선 사항은 다음과 같습니다.

* ONTAP 시스템 및 ASA r2 시스템을 위한 데이터 저장소 수준 보호
* 자동 페일오버 듀플렉스(AFD) 및 비동기 보호 정책
* iSCSI 및 FC VMFS 데이터스토어 지원
* 계층적 일관성 그룹 및 팬아웃 구성
* 함께 보호할 데이터 저장소를 선택하여 일관성 그룹 멤버십 제어
* 균일 및 비균일 AFD 보호 구성
* 데이터 저장소 및 호스트를 추가하거나 제거하여 보호 수준을 수정할 수 있는 기능
* vCenter 플러그인의 데이터 저장소 보호 워크플로
* 호스트 클러스터 보호에서 데이터스토어 수준 보호로의 업그레이드 경로




[[audit-logging]]
== 감사 로깅

ONTAP tools 10.6에는 보안 및 운영 추적성을 향상시키기 위한 감사 로깅 기능이 추가되었습니다.

감사 로깅에는 다음이 포함됩니다.

* GET 요청을 제외한 모든 REST API 호출(요청 및 응답 세부 정보 포함)
* 검색 작업, AutoSupport 번들 작업, 정리 작업 및 유지 관리 콘솔 작업
* 감사 로그 아카이브의 무결성 보호(변조 및 삭제 경고 포함)
* Syslog 전달 지원


이러한 업데이트는 규정 준수 및 보안 요구 사항을 지원합니다.



[[nconnect-support-for-nfs-datastores]]
== NFS 데이터스토어용 nconnect 지원

ONTAP tools 10.6은 VMware NFS 데이터스토어에 대한 nconnect 지원을 추가하여 ESXi 호스트와 ONTAP NFS 데이터스토어 간에 여러 개의 병렬 TCP 연결을 가능하게 합니다.

이번 릴리스는 다음을 지원합니다.

* 프로비저닝 중 NFSv3 데이터스토어용 nconnect
* vCenter 8.0U3 이상 버전에서 NFSv4.1 데이터스토어 프로비저닝 중 nconnect 사용
* ESXi 호스트에서 최대 nconnect 값 수정


이는 멀티 VM 워크로드에 대한 처리량 및 NFS 데이터 저장소 성능 향상에 도움이 됩니다.



[[smaller-default-deployment-with-xs-profile]]
== XS 프로필을 사용한 더 작은 기본 배포

ONTAP tools 10.6에서는 리소스 오버헤드를 줄이고 초기 배포를 간소화하기 위해 더 작은 기본 초소형(XS) 배포 프로파일을 도입했습니다.

개선 사항은 다음과 같습니다.

* 초기 배포의 기본 구성으로 XS
* 최적화된 기본 하드웨어 설정으로 OVA 배포
* XS를 사용한 데이터 저장소 프로비저닝, 보호, SRA 서비스 활성화 및 HA 모드 지원
* 관리자 UI에서 사용할 수 있는 배포 프로필은 초소형(XS), 소형(S), 중형(M), 대형(L)의 네 가지입니다.


이 모델은 초기 설치 공간이 적으면서도 명확한 확장 경로를 제공합니다.



[[ease-of-deployment-improvement]]
== 배포 용이성 개선

ONTAP tools 10.6은 기본 ONTAP tools VM을 새로 배포할 때 CPU 핫 추가 및 메모리 핫 플러그를 기본적으로 지원합니다.

이렇게 하면 배포 전후에 이러한 설정을 수동으로 활성화할 필요가 없어집니다.



[[protection-workflow-improvement]]
== 보호 워크플로 개선

ONTAP tools 10.6에서는 ONTAP 클러스터를 사용할 수 없을 때 스토리지 검색을 수동으로 트리거해야 하는 요구 사항이 제거되어 보호 워크플로가 간소화됩니다.



[[platform-and-interoperability-qualification]]
== 플랫폼 및 상호 운용성 검증

ONTAP tools 10.6은 주요 ONTAP 및 VMware 릴리스 전반에 걸쳐 플랫폼 및 상호 운용성 지원을 확장하여 VMware 환경에서 NetApp 스토리지를 원활하게 통합할 수 있도록 합니다.

이번 릴리스는 현재 ONTAP 플랫폼 구성 및 VMware 릴리스와 일치하여 플랫폼 업그레이드 및 VMware 스택 새로 고침 시 운영 복잡성을 줄입니다.



[[supportability-enhancements]]
== 지원 가능성 향상

ONTAP tools 10.6은 문제 해결 및 수명 주기 관리를 개선합니다.

주요 업데이트 사항은 다음과 같습니다.

* 접근할 수 없거나 오래된 vCenter 항목 강제 삭제
* 시간 동기화를 위해  `ntpd`에서  `chronyd`로 마이그레이션하며, 업그레이드 중 기존 NTP 서버 설정이 자동으로 마이그레이션됩니다.
* 유지 관리 콘솔에서 만료 후에도 내부 서비스 인증서를 갱신할 수 있는 옵션이 제공됩니다.
* 기존 NTP 서버와 표준 NTP 프로토콜(UDP 포트 123)을 통한 RHEL 기반 chrony 서버 모두 지원합니다.


최신 버전 호환성 정보는  https://mysupport.netapp.com/matrix["NetApp 상호 운용성 매트릭스 툴"^]을 참조하십시오.
