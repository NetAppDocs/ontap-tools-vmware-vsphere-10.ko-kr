= ONTAP tools for VMware vSphere 10.6 릴리스 노트
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이 페이지에서 ONTAP tools for VMware vSphere 10.6에 대한 주요 정보를 검토한 다음, 링크된 항목을 참조하여 기능 세부 정보, 호환성 및 마이그레이션 정보를 확인하십시오.

새로운 기능 및 개선 사항의 전체 목록은 xref:whats-new.adoc[ONTAP tools for VMware vSphere 10.6의 새로운 기능]을 참조하십시오.

최신 호환성 정보는 https://mysupport.netapp.com/matrix["NetApp 상호 운용성 매트릭스 툴"^]을 참조하십시오.

ONTAP tools for VMware vSphere 9.12D1, 9.13D2 및 9.13P2 릴리스에서 ONTAP tools for VMware vSphere 10.6으로의 마이그레이션이 지원됩니다.

자세한 내용은  https://library.netapp.com/ecm/ecm_download_file/ECMLP3383264["ONTAP tools for VMware vSphere 10.6 릴리스 노트"^]을 참조하십시오. 이 문서에 액세스하려면 NetApp 계정으로 로그인하거나 새 계정을 만들어야 합니다.
