= 다른 ONTAP tools 노드에서 SSH를 시작하세요
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP tools for VMware vSphere를 업그레이드하기 전에 환경의 다른 각 노드에서 SSH를 시작해야 합니다.

.시작하기 전에
vCenter Server 인스턴스에 대해 VASA 공급자 확장 기능을 활성화합니다.

.이 작업에 대해
업그레이드하기 전에 각 노드에서 이 절차를 반복하세요.

.단계
. vCenter 서버에 로그인합니다.
. ONTAP tools 노드 VM을 찾아 웹 콘솔을 실행합니다.
.  `maint` 자격 증명을 사용하여 로그인합니다.
. 를 입력합니다 `4` 지원 및 진단 을 선택합니다.
. 를 입력합니다 `1` 진단 쉘 액세스를 선택합니다.
. 를 입력합니다 `y` 를 눌러 계속합니다.
. _sudo systemctl restart ssh_ 명령을 실행합니다.
