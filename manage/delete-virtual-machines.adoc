= ONTAP tools에서 VASA 구성을 정리합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP tools에서 VASA 정리를 완료하려면 다음 단계를 따르십시오.


NOTE: VASA 정리 작업을 시작하기 전에 vVols 데이터 저장소를 모두 제거하십시오.

.단계
. 열기 `\https://OTV_IP:8143/Register.html` 플러그인 등록을 해제합니다.
. vCenter Server에서 플러그인을 더 이상 사용할 수 없는지 확인합니다.
. ONTAP tools for VMware vSphere 가상 머신(VM)을 종료합니다.
. VMware vSphere VM용 ONTAP 툴을 삭제합니다.
