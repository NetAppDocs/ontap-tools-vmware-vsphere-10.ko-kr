= ONTAP tools에 VMware vSphere 호스트 추가
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
새로운 VMware vSphere 호스트를 ONTAP tools for VMware vSphere에 추가하여 호스트 데이터스토어를 관리하고 보호할 수 있습니다.

.단계
. 다음 지침에 따라 VMware vSphere 클러스터에 호스트를 추가하십시오. https://techdocs.broadcom.com/["Broadcom 기술 문서"]
. 호스트를 추가한 후 ONTAP 툴 메인 메뉴로 이동하여 개요 패널에서 *검색*을 선택하거나 예약된 호스트 검색이 완료될 때까지 기다리십시오.


.결과
이제 새 호스트가 ONTAP tools for VMware vSphere에 의해 검색되고 관리됩니다. 이제 해당 호스트의 데이터스토어를 관리할 수 있습니다.

.관련 항목

* link:../manage/mount-datastores-on-host.html["NFS 및 VMFS 데이터 저장소를 마운트합니다"]새로운 호스트에서.
