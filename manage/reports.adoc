= ONTAP tools for VMware vSphere 보고서
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP tools for VMware vSphere 플러그인은 ONTAP 스토리지를 기반으로 하는 가상 머신 및 데이터스토어를 모니터링하는 데 도움이 되는 보고서를 제공합니다. 이러한 보고서를 보려면 vCenter 클라이언트의 바로 가기 섹션에서 ONTAP tools for VMware vSphere 플러그인 아이콘을 선택한 다음 보고서 탭을 선택하십시오.

가상 머신 보고서에는 ONTAP 스토리지 기반 데이터스토어에 디스크가 하나 이상 있는 검색된 가상 머신과 성능 지표가 나열됩니다. VM 레코드를 확장하면 인터페이스에 디스크 관련 데이터스토어 정보가 모두 표시됩니다.

데이터 저장소 보고서에는 ONTAP tools for VMware vSphere가 검색하고 ONTAP 스토리지를 사용하는 데이터 저장소와 성능 지표가 나열됩니다.

열 관리 옵션을 사용하여 다른 열을 숨기거나 표시할 수 있습니다.
