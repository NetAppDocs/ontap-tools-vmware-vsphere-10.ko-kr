= VMware vSphere 배포를 위한 ONTAP tools 제거
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP tools for VMware vSphere를 제거하면 어플라이언스의 데이터가 삭제되므로 예기치 않은 데이터 손실을 방지하려면 다음 단계를 완료하여 배포를 안전하게 종료하십시오.

.단계
. VMware vSphere에서 관리하는 데이터 저장소용 ONTAP 툴에서 모든 가상 머신을 제거하거나 이동합니다.
+
** 가상 머신을 제거하려면 을 참조하십시오 https://techdocs.broadcom.com/us/en/vmware-cis/vsphere/vsphere/8-0/vsphere-virtual-machine-administration-guide-8-0/managing-virtual-machinesvsphere-vm-admin/adding-and-removing-virtual-machinesvsphere-vm-admin.html#GUID-376174FE-F936-4BE4-B8C2-48EED42F110B-en["VM 및 VM 템플릿을 제거하고 다시 등록합니다"]
** 관리되지 않는 데이터스토어로 이동하려면 Storage vMotion을 사용하여 가상 머신을 마이그레이션하는 방법에 대해  https://techdocs.broadcom.com/["Broadcom 기술 문서"]을 참조하십시오


. link:../manage/delete-ds.html["데이터 저장소를 삭제합니다"] VMware vSphere용 ONTAP 툴에 생성되었습니다.
. VASA 공급자를 활성화한 경우 ONTAP 툴에서 *설정* > *VASA 공급자 설정* > *등록 취소* 를 선택하여 모든 vCenter Server 인스턴스에서 VASA 공급자의 등록을 해제하십시오.
. VMware Live Site Recovery에서 SRA 어댑터 제거:
+
.. 포트 5480을 사용하여 VMware Live Site Recovery 어플라이언스 관리 인터페이스에 admin으로 로그인합니다.
.. Storage Replication Adapters * 를 선택합니다.
.. 해당 SRA 카드를 선택하고 드롭다운 메뉴에서 * Delete * 를 선택합니다.
.. 어댑터 삭제 결과를 알고 있는지 확인하고 * 삭제 * 를 선택합니다.


. ONTAP tools for VMware vSphere에 온보딩된 vCenter Server 인스턴스를 제거합니다. link:../manage/manage-vcenter.html["vCenter Server 인스턴스를 관리합니다"]을 참조하십시오.
+
vCenter Server 인스턴스를 제거할 때 ONTAP tools에서 필요한 정리 작업을 안내합니다. *vCenter 제거* 대화 상자에 메시지가 표시되면 *이 vCenter Server에서 모든 스토리지 아티팩트 제거* 및 *관련 데이터스토어는 더 이상 ONTAP tools에서 관리되지 않음을 이해합니다*를 선택한 다음 *강제 삭제*를 선택하십시오.

+
*강제 삭제*를 사용하기 전에 모든 vVols 데이터스토어가 제거되거나 마이그레이션되었는지, 모든 보호된 데이터스토어가 보호 해제되었는지, 그리고 검색 작업이 실행 중이지 않은지 확인하십시오.

+
vCenter Server를 삭제하는 동안 연결할 수 없는 경우 ONTAP tools는 vCenter Server 레코드만 제거합니다. VMware vCenter Server에서 플러그인을 수동으로 등록 해제해야 합니다.

. vCenter Server에서 VMware vSphere VM용 ONTAP 툴의 전원을 끄고 VM을 삭제합니다.
