= ONTAP tools에서 vVols 데이터스토어 확장
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
vCenter 오브젝트 보기에서 데이터스토어 오브젝트를 마우스 오른쪽 버튼으로 클릭하면 플러그인 섹션에 ONTAP tools for VMware vSphere에 대해 지원되는 작업이 표시됩니다. 사용 가능한 작업은 데이터스토어 유형과 현재 사용자 Privileges에 따라 다릅니다.


NOTE: 이 절차는 ASA r2 시스템 기반 vVols 데이터스토어에는 적용되지 않습니다.

.단계
. vSphere Client 홈 페이지에서 * 호스트 및 클러스터 * 를 선택합니다.
. 탐색 창에서 데이터 저장소가 포함된 데이터 센터를 선택합니다.
. 데이터 저장소를 마우스 오른쪽 버튼으로 클릭하고 * NetApp ONTAP tools * > * Add storage to datastore * 를 선택합니다.
. *볼륨 생성 또는 선택* 창에서 새 볼륨을 생성하거나 기존 볼륨에서 선택할 수 있습니다. 화면의 지시에 따라 선택하세요.
. Summary * 창에서 선택 사항을 검토하고 * Expand * 를 선택합니다. 최근 작업 패널에서 진행 상황을 추적할 수 있습니다.
