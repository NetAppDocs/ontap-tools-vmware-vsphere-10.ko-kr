= ONTAP 도구 관리자 암호를 변경합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP tools Manager에서 관리자 암호를 변경할 수 있습니다.

.단계
. 웹 브라우저에서 ONTAP 도구 관리자를 실행합니다. `\https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. ONTAP tools for VMware vSphere 사용하여 로그인하세요.
. 오른쪽 상단의 *관리자* 아이콘을 선택한 다음 *비밀번호 변경*을 선택합니다.
. *암호 변경* 대화 상자에서 이전 암호와 새 암호를 입력합니다. 거기에 표시된 암호 요구 사항을 검토하십시오.
. 변경 사항을 적용하려면 *변경*을 선택하세요.
