= ONTAP 툴을 사용하여 ESXi 호스트 설정을 수정합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
VMware vSphere의 ONTAP 툴 대시보드를 사용하여 구성 문제를 식별하고, 선택한 ESXi 호스트에 대해 NetApp에서 권장하는 설정을 검토하고 적용하십시오.

.시작하기 전에
ESXi 호스트 시스템 포틀릿은 ESXi 호스트 설정과 관련된 문제를 표시합니다.  호스트 이름이나 IP 주소를 보려면 문제를 선택하세요.

.단계
. vSphere 클라이언트에 로그인합니다.
. 바로가기 페이지의 플러그인 섹션에서 *NetApp ONTAP tools*를 선택합니다.
. ONTAP tools for VMware vSphere 플러그인의 개요 대시보드에서 *ESXi 호스트 규정 준수* 포틀릿으로 이동합니다.
. *권장 설정 적용* 링크를 선택합니다.
. *권장 호스트 설정 적용* 창에서 NetApp 권장 호스트 설정을 적용할 호스트를 선택한 다음 *다음*을 선택합니다.
+

NOTE: ESXi 호스트를 확장하여 현재 값을 볼 수 있습니다.

. 설정 페이지에서 필요에 따라 권장 값을 선택하십시오.
. 요약 창에서 값을 확인하고 *완료*를 선택합니다. 최근 작업 창에서 진행 상황을 확인할 수 있습니다.
