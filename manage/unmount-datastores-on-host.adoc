= ONTAP 도구에서 NFS 및 VMFS 데이터 저장소 마운트 해제
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이 작업을 사용하여 ESXi 호스트에서 NFS 또는 VMFS 데이터스토어를 마운트 해제할 수 있습니다. 클러스터 수준의 데이터스토어 마운트 해제는 UI 또는 API를 통해 지원되지 않습니다.

ONTAP tools 10.6부터 보호된 VMFS 데이터스토어의 마운트 해제가 차단됩니다.

.단계
. vSphere Client에 로그인합니다.
. NFS 또는 VMFS 데이터스토어 개체를 마우스 오른쪽 버튼으로 클릭하고 *데이터스토어 마운트 해제*를 선택합니다.
+
vSphere 클라이언트는 데이터스토어를 마운트한 ESXi 호스트 목록을 표시하는 대화 상자를 엽니다. 데이터스토어가 보호되어 있는 경우 ONTAP tools는 요청을 차단하고 데이터스토어가 보호 중이므로 마운트 해제할 수 없다는 메시지를 표시합니다.

. 데이터 저장소를 마운트 해제할 ESXi 호스트를 하나 이상 선택합니다.
+
모든 호스트에서 데이터 저장소를 마운트 해제할 수 없습니다. 사용자 인터페이스에서 데이터 저장소 삭제 작업을 대신 사용할 것을 제안합니다.

. Unmount * 버튼을 선택합니다.
+
*데이터 저장소 마운트 해제* 옵션은 호스트가 보호된 호스트 클러스터 외부로 이동된 경우에만 사용할 수 있습니다.




NOTE: 데이터 저장소가 보호되어 있는 경우, 마운트 해제하기 전에 먼저 보호를 해제해야 합니다.
