= ONTAP tools 확장 및 고가용성 활성화
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP Tools Manager를 사용하여 어플라이언스를 확장하고 고가용성(HA)을 구성하십시오. 기본적으로 ONTAP tools for VMware vSphere는 단일 노드, 비HA 구성으로 배포됩니다.

.시작하기 전에
* OVA 템플릿 버전이 노드 1(초기 배포 노드)의 버전과 일치하는지 확인하십시오.
* 하이퍼바이저에서 CPU 핫 추가 및 메모리 핫 플러그를 활성화합니다. 이러한 기능은 어플라이언스의 스케일 업 및 고가용성(HA) 활성화에 필요합니다. ONTAP tools 10.6 이상 버전에서는 이러한 기능이 기본적으로 활성화되어 있습니다. 이전 버전의 경우 스케일 업 또는 HA 활성화 전에 이러한 기능을 활성화해야 합니다.
* vCenter Server에서 재해 복구 서비스(DRS) 자동화 수준을 부분 자동화로 설정합니다. HA 배포가 완료되면 완전 자동화로 되돌립니다.
+

NOTE: 노드 크기는 늘릴 수는 있지만 줄일 수는 없습니다. 초소형(XS) 배포 환경에서는 특정 서비스가 제한됩니다.



.단계
. ONTAP tools Manager를 실행합니다: `\https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. ONTAP tools 관리자 자격 증명으로 로그인하십시오.
. 개요 섹션에서 *기기 설정 편집*을 선택합니다.
. *구성* 섹션에서 새 노드 크기를 선택하고 HA 스위치를 켜서 고가용성을 활성화하십시오.
. *HA 설정* 페이지에서 다음 사항을 확인하십시오:
+
** 콘텐츠 라이브러리는 ONTAP tools VM이 실행될 vCenter Server와 동일한 서버에 있습니다.
** ONTAP tools의 VM은 ESXi 호스트에 직접 배포되는 것이 아니라 클러스터 또는 리소스 풀에 배포됩니다.
+

IMPORTANT: HA를 활성화한 후에는 HA를 사용하지 않는 단일 노드 구성으로 되돌릴 수 없습니다.



. *HA 설정* 섹션에서 노드 2와 3에 대한 네트워크 정보를 입력하십시오. ONTAP tools는 HA 모드에서 세 개의 노드를 지원합니다.
+
ONTAP tools는 대부분의 필드를 노드 1의 네트워크 설정으로 미리 채웁니다. 마법사를 완료하기 전에 이러한 값을 편집할 수 있습니다. IPv6 주소 항목은 관리 노드에서 IPv6가 활성화된 경우에만 사용할 수 있습니다. 각 ESXi 호스트에는 ONTAP tools VM이 하나만 있어야 합니다.

. 요약을 검토하고 *저장*을 클릭합니다.


.결과
어플라이언스가 스케일링 및 고가용성(HA) 활성화를 시작합니다. *개요* 페이지에서 진행 상황을 모니터링하거나 *작업* 보기에서 작업 ID를 사용하여 작업을 추적할 수 있습니다.

HA 배포가 '새로 생성됨' 상태로 실패하면 vCenter에서 실패한 VM을 삭제하고 다시 시도하십시오.

진행 과정에서 발생할 수 있는 경고나 문제점을 확인하려면 *알림* 탭을 검토하십시오.
