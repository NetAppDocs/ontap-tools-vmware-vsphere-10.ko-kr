= ONTAP 도구에서 데이터 저장소를 삭제합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
vCenter Server에서 ONTAP tools를 사용하여 NFS, VMFS 또는 vVols 데이터스토어를 삭제하려면 이 작업을 사용하십시오. 삭제 동작 및 정리 옵션은 데이터스토어 유형에 따라 다릅니다.

.NFS 및 VMFS 데이터스토어의 삭제 동작
* 가상 머신에서 사용하는 데이터 저장소는 삭제할 수 없습니다.
* 보호 대상 호스트 클러스터의 경우 추가적인 보호 제약 조건이 적용됩니다.


.vVols 데이터스토어의 삭제 동작
vVols 데이터스토어의 경우 다음 작업이 수행됩니다:

* vVol 컨테이너가 마운트 해제되었습니다.
* igroup이 사용되지 않으면 해당 이니시에이터가 igroup에서 제거됩니다.
* vVol 컨테이너가 삭제되었습니다.
* Flex 볼륨은 스토리지 어레이에 남아 있습니다.


vVols 데이터스토어의 경우, 선택한 데이터스토어에 vVols가 없는 경우에만 데이터스토어를 삭제할 수 있습니다.

.시작하기 전에
* 데이터 저장소가 가상 머신에서 사용 중이 아닌지 확인하십시오.
* 데이터 저장소가 보호된 호스트 클러스터에 속하는지 확인하십시오.
* 데이터스토어 삭제 시 ONTAP 클러스터의 백업 볼륨을 삭제할지 여부를 결정합니다.


[cols="1,1,2,2"]
|===
| 데이터 저장소 유형 | 삭제할 수 있습니까? | 주요 차단 조건 | ONTAP 정리 옵션 


| NFS | 예 | 해당 데이터 저장소는 가상 머신에서 사용 중입니다. | 필요한 경우 *ONTAP 클러스터에서 볼륨 삭제*를 선택할 수 있습니다. 


| VMFS | 예 | 해당 데이터 저장소는 가상 머신에서 사용 중이거나 호스트 클러스터 보호 제약 조건이 적용됩니다. | *ONTAP 클러스터에서 볼륨 삭제*를 선택할 수 있습니다. ONTAP 스토리지의 보호된 호스트 클러스터의 경우 ONTAP에서 볼륨 삭제는 지원되지 않습니다. 


| vVols | 네, 조건부로 | 데이터 저장소에 하나 이상의 vVols이 있습니다. | ONTAP에서 볼륨을 제거하는 옵션을 선택할 수 있습니다. 단, ASA r2의 경우 이 워크플로에서 ONTAP의 백업 볼륨 삭제는 지원되지 않습니다. 
|===
.단계
. vSphere 클라이언트에 로그인합니다.
. 호스트 시스템, 호스트 클러스터 또는 데이터 센터를 마우스 오른쪽 버튼으로 클릭하고 * NetApp ONTAP 도구* > *데이터 저장소 삭제*를 선택합니다.
+

NOTE: 가상 머신에서 사용하는 데이터 저장소는 삭제할 수 없습니다. 삭제하기 전에 가상 머신을 다른 데이터 저장소로 이동하십시오.

+

NOTE: 데이터 저장소가 보호된 호스트 클러스터의 일부인 경우 삭제하기 전에 보호 제약 조건을 검토하십시오.

+
.. NFS 또는 VMFS 데이터스토어의 경우, 해당 데이터스토어를 사용하는 가상 머신 목록이 포함된 대화 상자가 나타납니다.
.. VMFS 데이터스토어에 연결된 가상 머신이 없는 경우 확인 대화 상자가 표시됩니다. 호스트 클러스터 보호가 활성화되어 있고 자동 장애 조치 이중화(AFD) 관계가 있는 경우 2차 스토리지 요소를 정리할 수 있습니다.
.. ASA r2 스토리지 시스템의 보호된 VMFS 데이터스토어의 경우 삭제하기 전에 보호를 해제해야 합니다. ONTAP 9.17.1 및 ONTAP tools for VMware vSphere 10.5부터는 보호된 데이터스토어를 삭제할 수 있습니다.
+
자동 장애 조치 이중화(AFD)를 사용한 마지막 데이터 저장소 삭제 시 ONTAP tools에는 다음과 같은 메시지가 표시됩니다. *데이터 저장소가 보호되어 있습니다. 삭제하기 전에 보호가 해제됩니다.*

+
보호 그룹에서 마지막으로 보호된 데이터 저장소를 삭제하면 ONTAP tools에서 마지막 데이터 저장소를 삭제하면 데이터 저장소가 보호되지 않게 된다는 메시지가 표시됩니다.

.. vVols 데이터 저장소의 경우 vVols 가 없는 경우에만 데이터 저장소를 삭제할 수 있습니다.  *데이터 저장소 삭제* 대화 상자에는 ONTAP 클러스터에서 볼륨을 제거하는 옵션이 포함되어 있습니다.
.. ASA r2 스토리지 시스템의 vVols 데이터스토어의 경우, *데이터스토어 삭제* 옵션을 사용하여 ONTAP에서 백업 볼륨을 삭제할 수 없습니다.


. ONTAP 스토리지에서 백업 볼륨을 삭제하려면 * Delete volumes on ONTAP cluster * 를 선택합니다.
+

NOTE: 보호된 호스트 클러스터의 일부인 ONTAP 스토리지의 VMFS 데이터스토어의 경우 ONTAP 클러스터에서 볼륨을 삭제할 수 없습니다.



NFS, VMFS 또는 vVols 데이터스토어를 삭제하면 상위 igroup은 ONTAP 시스템에 남아 있습니다. LUN에 매핑되지 않은 하위 igroup은 자동으로 삭제됩니다. ONTAP tools는 매핑되지 않은 기본 상위 igroup을 제거하기 위해 매일 정리 작업을 수행합니다. 사용자 지정 상위 igroup은 ONTAP에서 수동으로 삭제하십시오. ONTAP tools는 오래된 상위 igroup을 재사용할 수 없습니다.
