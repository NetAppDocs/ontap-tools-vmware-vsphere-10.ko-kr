= ONTAP 도구에서 네트워크 액세스 구성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
기본적으로 네트워크 액세스를 구성하지 않는 한 ONTAP 툴은 ESXi 호스트에서 검색된 모든 IP 주소를 내보내기 정책에 자동으로 추가합니다. 내보내기 정책을 수정하여 특정 IP 주소에서만 액세스를 허용할 수 있습니다. 제외된 ESXi 호스트에 대해서는 마운트 작업이 실패합니다.

.단계
. vSphere Client에 로그인합니다.
. 플러그인 섹션의 바로가기 페이지에서 *NetApp ONTAP tools*를 선택하십시오.
. ONTAP 도구의 왼쪽 창에서 *설정* > *네트워크 액세스 관리* > *편집*으로 이동합니다.
+
여러 IP 주소를 추가하려면 쉼표, 범위, CIDR(Classless Inter-Domain Routing) 표기법 또는 이 세 가지를 모두 조합하여 목록을 구분하십시오.

. 저장 * 을 선택합니다.
